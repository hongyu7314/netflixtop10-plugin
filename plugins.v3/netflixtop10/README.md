# 网飞排行榜（NetflixTop10）

MoviePilot V3 插件。基于 Netflix 官方公开的 [Tudum Top 10](https://www.netflix.com/tudum/top10) 周榜数据，覆盖 **剧集（英语/非英语）+ 电影（英语/非英语）** 共四个榜单分类。

**v1.1.0 新增**：
- 📌 **详情页顶部一键切换榜单地区**：全球 / 中国香港 / 美国 / 韩国 / 日本
- 🖼️ **海报墙**：160×240 大海报，参考猫眼热度榜尺寸
- 🔗 **点击海报直接跳转 MoviePilot 系统详情页**（`#/media?media_source=themoviedb&...`）

每周自动刷新，TMDB 识别媒体信息后可在 MoviePilot 内浏览榜单、一键订阅、新上榜提醒、自动订阅。

## 数据来源

Netflix 官方公开的 TSV 文件，每周一更新（北京时间周二发布）：

| 文件 | 维度 | 字段 |
| --- | --- | --- |
| `all-weeks-global.tsv` | 全球榜（4 个分类） | 周观看时长、观看次数、片长、上榜累计周数 |
| `all-weeks-countries.tsv` | 90+ 国家/地区（4 个分类） | 仅排名与上榜累计周数 |

> 数据抓取通过 `requests` 自带代理设置，遵循 MoviePilot 全局代理配置。极端情况下（Netflix 拒绝请求）会自动重试 2 次。

## 功能特性

| 模块 | 说明 |
| --- | --- |
| 🖼️ **海报墙** | 详情页用 Vuetify 卡片网格（每行 2-6 列响应式）呈现，海报 160×240（参考猫眼热度榜尺寸） |
| 🔗 **点击进系统详情** | 海报卡片整体为 `<a href="#/media?...">` 链接，MoviePilot 前端 SPA 内跳转至媒体详情页（含海报/演员/订阅入口） |
| 🌍 **5 地区一键切换** | 详情页顶部 5 个 toggle 按钮：全球 / 中国香港 / 美国 / 韩国 / 日本，切换后立即后台抓取新地区（约 1-2 分钟） |
| 🔔 **新上榜提醒** | 新一周发布后，对比上周榜，新上榜 / 排名跃升 TOP3 / 新入榜首的剧集电影触发通知 |
| ⚡ **一键订阅** | 卡片内嵌订阅按钮，调用 `/subscribe` API；已订阅/已入库自动标识 |
| 🤖 **自动订阅** | 可选对新上榜 + 未订阅的作品自动发起订阅 |
| 💾 **缓存复用** | 已抓取过的 TMDB/详情信息跨周/跨地区复用，避免重复请求 |

## 安装

### 方式一：市场安装（推荐）
MoviePilot V3 插件市场搜索 **网飞排行榜** 一键安装。

### 方式二：手动安装
将 `plugins.v3/netflixtop10/` 目录放入 MoviePilot `plugins.v3/` 目录下，重启 MoviePilot，插件管理中启用。

### 方式三：Git 安装
插件管理 → 安装插件 → Git 安装，填入：

```
https://github.com/hongyu7314/netflixtop10-plugin
```

## 配置项

启用插件后，在 **设置 → 插件 → 网飞排行榜** 中可调整：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 启用插件 | ❌ | 总开关 |
| 启用新上榜提醒 | ❌ | 新上榜 / 排名跃升触发通知 |
| 自动订阅新上榜 | ❌ | 对新上榜 + 未订阅的作品自动添加订阅 |
| 榜单范围 | 全球 | 默认抓取的地区（详情页有独立 5 地区切换器覆盖） |
| 自动刷新间隔 | 6 小时 | Netflix 周榜每周二更新 |
| 榜单分类 | 全选 | 剧集英语 / 剧集非英语 / 电影英语 / 电影非英语 |
| 消息类型 | Plugin | 通知消息类型 |
| 保存后立即运行一次 | ❌ | 保存配置时立即触发一次刷新 |

```
│ │#1  │ │#2  │ │#3  │ │#4  │ │#5  │               │

│  [订阅]  [订阅]  [已订阅][订阅] [订阅]            │

```

每张海报卡片：
- **整体可点击** → 跳转 MoviePilot 系统详情页（`/media?media_source=themoviedb&media_id={tmdbid}&title=...&year=...&type=...`）
- **左上角** 排名标签（No.1 ~ No.10）
- **底部** 状态徽章（未添加订阅 / 订阅已添加 / 影片已入库）
- **下方** 中文/英文标题、副标题（年份/季/上榜周数）、观看数据、订阅按钮

## API 路径

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/plugin/NetflixTop10/subscribe` | 一键订阅（query: `tmdbid`, `name`, `mtype`, `apikey`） |
| `GET` | `/plugin/NetflixTop10/run-once` | 立即刷新一次（同步执行） |
| `GET` | `/plugin/NetflixTop10/get-cache` | 获取当前缓存（含订阅状态重算） |
| `GET` | `/plugin/NetflixTop10/clear-cache` | 清空所有插件缓存 + 静默重建 |
| `GET` | `/plugin/NetflixTop10/switch-region?scope={scope}&apikey={...}` | 切换详情页展示的地区榜单（5 个预设之一） |

鉴权使用 MoviePilot 默认 `apikey`（由前端 `events` 自动附带）。

`scope` 取值：`global` / `Hong Kong` / `United States` / `South Korea` / `Japan`，非法值自动 fallback 到 `global`。

## 异常与边界

- **TMDB 识别失败** → 海报占位 + 订阅按钮禁用（不影响其他条目）
- **网络被 Netflix 拒绝** → 自动重试 2 次（指数退避），失败后保留旧数据 + 错误日志
- **TSV 格式变化** → `scraper.parse_tsv` 会因缺列抛出 `ValueError`，插件捕获后告警但不崩溃
- **地区切换网络失败** → 详情页顶部 alert 显示"切换中"，旧缓存继续展示，后台线程重试
- **容器重启后 view_scope 恢复** → 通过独立 `netflixtop10_view_scope` 缓存键持久化
